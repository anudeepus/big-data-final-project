# Big Data Processing and Analytics Pipeline

## Project Overview
This project demonstrates a layered data processing and analytics workflow using Python and Cassandra. The pipeline is organized into Bronze, Silver, and Gold processing stages.

## Technologies Used
- Python
- Apache Cassandra
- Pandas
- Scikit-learn
- Data Visualization

## Pipeline Architecture
**Bronze Layer:** Ingests source CSV data into Cassandra.

**Silver Layer:** Provides an intermediate data processing stage.

**Gold Layer:** Supports analytical processing, regression modeling, model evaluation using RMSE, and sales visualization.

## Skills Demonstrated
- Data ingestion and processing
- Layered data pipeline design
- Python programming
- NoSQL database integration
- Machine learning and analytics

## Project Purpose
Demonstrates practical data engineering and analytical processing concepts that can be applied to enterprise data platforms.
